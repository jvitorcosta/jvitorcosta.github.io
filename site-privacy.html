Privacy of this site and Ask Vitor

Last updated 2026-11-12

The website

No cookies, no analytics, no tracking. The page is plain files from GitHub Pages; fonts, icons and images are served from the site itself.

When the page loads, it makes one outside request: to my own Spotify server on Vercel, to show what I am listening to. If that server does not send the cover inline, the browser may also fetch the cover from Spotify's image host.

Ask Vitor

The Ask Vitor dialogue (when it is turned on) loads nothing until you open TALK / ASK ME and send a question.

  • Where it goes: your question goes to the ask-vitor API, hosted on Vercel. The API sends it, together with the public knowledge file published on this site (knowledge.json), to Anthropic's Claude API, which writes the answer. Anthropic processes the question under its own API data policy.
  • What is saved: for each question, the question, the answer, which sources were used, the type of reply (an answer, the standard ‘no information’ reply, or the off-topic reply), how long it took, and the date. Emails and phone numbers are removed before saving. It is kept in a log store (Upstash Redis) and deleted after 90 days.
  • What is never saved in the question log: your IP address, browser details (user agent), cookies, session ids. The IP address is kept only in memory, for at most an hour, to count questions per visitor (a rate limit).

Like any website, the hosting providers (GitHub Pages for this site, Vercel for the API) receive your IP address when your browser connects; their own logs are outside this app.

Please do not type anything private into the question box.

Privacidade deste site e do Ask Vitor

Atualizado em 2026-11-12

O site

Sem cookies, sem analytics, sem rastreamento. A página é feita de arquivos simples no GitHub Pages; fontes, ícones e imagens vêm do próprio site.

Quando a página carrega, ela faz uma requisição externa: ao meu servidor do Spotify na Vercel, para mostrar o que estou ouvindo. Se esse servidor não enviar a capa embutida, o navegador também pode buscar a capa no servidor de imagens do Spotify.

Ask Vitor

O diálogo do Ask Vitor (quando está ligado) não carrega nada até você abrir FALAR / PERGUNTE e enviar uma pergunta.

  • Para onde vai: sua pergunta vai para a API do ask-vitor, hospedada na Vercel. A API a envia, junto com o arquivo público de conhecimento publicado neste site (knowledge.json), para a API Claude da Anthropic, que escreve a resposta. A Anthropic trata a pergunta conforme a própria política de dados da API.
  • O que é salvo: para cada pergunta, a pergunta, a resposta, quais fontes foram usadas, o tipo de resposta (uma resposta, a resposta padrão de ‘sem informação’ ou a resposta de fora do assunto), quanto tempo levou e a data. E-mails e telefones são removidos antes de salvar. Fica num registro (Upstash Redis) e é apagado após 90 dias.
  • O que nunca é salvo no registro de perguntas: seu endereço IP, dados do navegador (user agent), cookies, ids de sessão. O IP fica só na memória, por no máximo uma hora, para contar perguntas por visitante (limite de uso).

Como em qualquer site, os provedores de hospedagem (GitHub Pages para este site, Vercel para a API) recebem seu endereço IP quando o navegador se conecta; os registros deles ficam fora deste app.

Por favor, não escreva nada privado na caixa de pergunta.
